## Question

What attribution and licensing boundaries must the ingestion implementation respect for the chosen sources?

Resolve practical requirements for:

- BuildCores OpenDB under ODC-By attribution;
- SFF Master List community spreadsheet attribution and non-explicit licensing caveats;
- SPL PSU Tier List usage and attribution;
- Cybenetics CSV/export usage;
- TechPowerUp licensed API versus dbgpu-derived data;
- PCPartPicker-derived snapshots or scrapers, if any are retained or ruled out.

The answer should distinguish required product/docs attribution from internal-only source metadata, and should identify any source that should not be ingested for licensing or ToS reasons.
